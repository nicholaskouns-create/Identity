Authoritative spin-sector construction

H = V₂ ⊗ V₂ ⊗ V₂, dim H = 125
C = (Jₓ¹+Jₓ²+Jₓ³)² + (Jᵧ¹+Jᵧ²+Jᵧ³)² + (J_z¹+J_z²+J_z³)²
spec C = {0,2,6,12,20,30,42}
multiplicities = {1,9,25,28,27,22,13}
K = (C−6I)(C−30I)
P₄₇ = 1_{{6,30}}(C), rank P₄₇ = 25 + 22 = 47
z₄₇ = P₄₇ z; η = ‖P₄₇z‖² / ‖z‖²

Here P₄₇ is evaluated as a degree-six Lagrange interpolation polynomial in C, using the exact seven Casimir eigenvalues. The resulting operator is a mathematical orthogonal projector; browser arithmetic introduces floating-point roundoff.

Interpretation: 47/125 = 0.376 is the subspace dimension fraction, not a guaranteed retention percentage for a particular image. η is measured separately for each input. RGB error measures the untrained direct readout, not optimized compression performance.
