04 / INSPECTABLE METHOD

Method.

An AI mirror should demonstrate where each reflection came from, what was inferred, and what remains unknown.

Σ / INPUT

Aggregation with consent

Only entered records and explicitly imported files are used. No account, background scraping, analytics profile, or hidden chat access.

Γ / NORMALIZE

Distinguish evidence types

User statements, repository records, computed results, external claims and inferences retain their separate labels. None is promoted to objective truth by naming it.

Λ / RETRIEVE

Relevance without fabrication

Transparent lexical overlap retrieves source statements. This ranking measures query relevance, not epistemic confidence. Inference does not become verified merely because a language model repeats it.

Ψ / REFLECT

Optional on-device language model

WebLLM provides browser-only text generation after the user loads model files. Generated text is marked as a model draft, with the input evidence shown separately. Unsupported devices retain deterministic source-bound reflection.

Ωₑ / EVIDENCE

Truth as an output constraint

Source-bound, possible tension and insufficient evidence remain distinct. DENSITY’s reported September 30 control did not support a P₄₇-specific advantage on its 11-observation seed; SEE does not repurpose P₄₇ as an unvalidated truth gate.

α / RESTART

Agency remains local

Edit, delete, import, export or clear records at any time. Nothing is automatically synchronized to Supabase or posted to City Pulse. SHA-256 receipts can detect accidental changes to exported bytes; they do not prove that a claim is true.
