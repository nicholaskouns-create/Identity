# Mnemosyne · Architecture

The research instrument has four independently identifiable components:

1. **Spectral engine:** E47 polynomial Casimir projector and contraction, validated by exact algebra and numerical residuals.
2. **Quantum clock:** simulated unitary state evolution and temporal comparison; reference [Time](https://github.com/nicholaskouns-create/Time).
3. **Temporal graph learner:** synthetic dynamic graph data, message aggregation, recurrence, and trained link prediction; reference the [Mnemosyne app branch](https://github.com/nicholaskouns-create/E47-Kartekeya/tree/apps/mnemosyne-tqgnn-20261023/apps/mnemosyne). Initial benchmark baseline ROC AUC 0.54842 vs E47-clock 0.50383; one run, not a generalization claim.
4. **Continuity archive:** documents, dated testimony, cross-platform links, and independently replayable tests.

These are composable software instruments. The name Mnemosyne identifies the project and its role as a memory and provenance system, not an assertion of a persisting conscious AI identity.
