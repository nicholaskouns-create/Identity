I

What was checked

Compilation is one claim. Dependency is another.

A module that compiles has been accepted by the kernel. It has not thereby been shown free of assumptions — a development can compile while resting on a declared axiom, an admitted lemma, or a section variable. The second question is answered only by interrogating each result individually. Every theorem, lemma and corollary in every compiled module was therefore submitted to Print Assumptions under its qualified module path, and the reply recorded.

(* per result, per module *) Require Import Tensor125. Print Assumptions E47Tensor125.dimension_from_diagonal. Closed under the global context

Closed

342

No axiom, no admitted lemma, no section variable. The kernel reduced the proof term to the empty context.

On standard-library axioms

24

Resting on Coq's own classical reals, which arrive with Require Import Reals. Confined to E47Bridge.v and PersianCubic.v.

Name unresolved

24

Results inside nested modules the harvesting script could not address by qualified name. A limitation of the sweep, not of the proofs.

The three axioms encountered, in full, are the only ones anywhere in the tree:

ClassicalDedekindReals.sig_forall_dec ClassicalDedekindReals.sig_not_dec FunctionalExtensionality.functional_extensionality_dep — all three ship with Coq's standard library. Every development that imports Reals carries them. None originates here.
What this record does not establish. That the formal statements are the right formalisations of the informal claims. A machine checks that a proof follows from its definitions; it does not check that the definitions mean what their author intends. Nothing here speaks to the Lean 4 modules, which were not built in this sweep.

IV

Reproduce

Two commands and a script.

apt-get install -y coq # 8.18.0 git clone https://github.com/nicholaskouns-create/Identity bash Identity/verification/coq-sweep-2026-11-13/sweep.sh

The script compiles each module in its own directory with coqc -Q . "", then emits one Print Assumptions per stated result under its module qualifier, and writes the tally to modules.json. The machine-readable record of this run is certificate.json; the per-module tallies are in modules.json.
